# 内置行为

内置行为是路径，不是语句。调用写成 `名字(参数, ...)`，命名参数写成 `名字: 表达式`。下表里的「失败」是该行为自己的条件。结构字段的 `check` 失败仍用结构的错误码。

路径拒绝空路径、空字节、`..` 和单独的 `.` 段。运行时的符号链接目标必须是相对路径，并且通过同一套检查。

## 文件

| 行为 | 参数 | 返回 | 失败 |
| --- | --- | --- | --- |
| `files` | 一个或多个已存在的文件路径 | 收进包的个数，整数 | 文件不存在或不可读 |
| `files.all` | `exclude: ["目录名", ...]`，可省略 | 收进包的个数，整数 | 当前目录不能列出 |
| `files.list` | 目录。`suffix` 字符串，`deep` 布尔，`exclude` 字符串列表，均可省略 | 文件路径的字符串列表。不收进包 | 目录不存在或不能列出 |
| `files.name` | 路径 | 最后一段文件名，字符串。不读文件 | 没有文件名 |
| `files.dir` | 路径 | 所在目录，字符串。只有文件名时是 `.`。不读文件 | 路径不安全 |
| `files.read.bytes` | 路径 | 字节 | 文件不存在或不可读 |
| `files.read.str` | 路径 | UTF-8 字符串 | 不是合法 UTF-8 |
| `files.write.bytes` | 路径，字节 | 写入的字节 | 父目录不可写，或第二个参数不是字节 |
| `files.write.str` | 路径，字符串 | 写入的字符串 | 父目录不可写，或第二个参数不是字符串 |
| `files.read` | 路径，结构名 | 一条记录。不收进包 | 载体或布局不符，或 `check` 失败 |
| `files.write` | 路径，记录 | 该记录 | 记录与结构不一致 |
| `files.rows` | 路径，结构名。`header: true` 只适用于 `split` | 记录列表。空文件得到空列表 | 结构不是 `split` 或 `json`。`header` 时第一行必须是字段名且顺序一致；空文件失败 |
| `files.each` | 路径，结构名，一个参数的行为。`header: true` 只适用于 `split` | 处理过的行数，整数。不返回列表，也不读取行为的 `result` | 与 `files.rows` 相同。某一行解码失败时停止，已处理的行保留 |
| `files.field` | 路径，`block` 结构名，两个参数的行为 | 字段个数。每块交给行为后丢掉，不组装记录 | 结构不是 `block`，或某一块不完整 |
| `crypto.pair` | 私钥路径，公钥路径。两个路径不能相同，文件都不能已存在 | 布尔值 true。写出 Ed25519 PKCS8 私钥和 32 字节公钥。公钥没写上时删掉刚写出的私钥 | 路径相同、任一文件已存在，或路径不能写 |
| `files.seal` | 数据包目录，Ed25519 PKCS8 私钥路径 | 布尔值 true。写出 `dake.pub` 和 `dake.seal`，私钥不进包 | 没有清单，或私钥不是 PKCS8 |
| `files.unseal` | 数据包目录，公钥路径。公钥须与包里的 `dake.pub` 相同 | 布尔值 true。核对清单原文，再按块重算每个文件的 blake3 | 公钥不一致、签名不符，或文件哈希不符 |
| `files.verify` | 数据包目录。`key` 是签名密钥。`depend` 是依赖包目录列表，顺序与清单 `depends` 一致。`replace` 是被替换包的目录 | 布尔值 true。会打开这些目录，按块核对名字、版本、哈希和签名 | 哈希不符、签名不符、名字或版本对不上，或清单有依赖/替换却没给目录 |
| `files.write.rows` | 路径，同一结构的记录列表。`header: true` 写字段名，`header: "一行"` 把该字符串写在第一行。`append: true` 追加 | 该列表 | `append` 与 `header` 同时给出。列表里混有别的结构 |
| `files.write.row` | 路径，一条记录。`header: true` 只在文件还不存在或为空时写 `split` 字段名 | 该记录。追加一行后丢掉，不读已有内容 | 结构不是 `split` 或 `json`。`header` 用于非 `split` |
| `files.encry` | 无 | 布尔值 true。此后写出的副本加密，并在输出目录写 `dake.key` | |
| `files.decry` | 密钥路径，密文字节 | 明文字节 | 密钥或密文无效 |

`files.list` 的 `suffix` 按文件名结尾匹配。`deep: true` 进入子目录。`exclude` 在递归时按目录名跳过。

`files.read.bytes`、`files.read.str`、`files.read` 和 `files.write.bytes` 按 1 MiB 一块进出磁盘。得到的值仍是整份字节、字符串或一条记录。`files.write.rows` 在 `append: true` 时只读文件最后一个字节；不是换行就先补一个，再把新行接到后面，不重写已有内容。

`files.encry` 和带 `key` 的 `pack` 按 1 MiB 分块加密。新密文以 `DAKE` 和版本字节 `2` 开头，每块自带 nonce。没有这个帧头的旧密文仍按整段解开。

## 共享

`share 名字` 是语句，不是内置行为。它把已经赋值的变量放进所有 `serve` 连接和 `await` 分支共用的表。

| 行为 | 参数 | 返回 | 失败 |
| --- | --- | --- | --- |
| `shared.add` | 已 `share` 的名字，整数 | 加上之后的整数。加的过程占着锁 | 名字没有共享，或当前值不是整数 |
| `shared.set` | 已 `share` 的名字，字段名，值 | 改过的记录或对象 | 名字没有共享，或值不是记录或对象。记录上字段不存在 |

## 记录与文本

| 行为 | 参数 | 返回 | 失败 |
| --- | --- | --- | --- |
| `record` | 结构名，然后成对的字段名与值 | 一条记录。有 `default` 的字段可省略 | 缺字段或类型不符 |
| `update` | 记录，字段名，值 | 新记录 | 字段不存在或类型不符 |
| `text.decode` | 文本，结构名 | 一条记录 | 切分或 `check` 失败 |
| `text.encode` | 记录 | 按该记录结构编码的字符串 | 布局不能编码成文本 |
| `text.lines` | 字符串 | 字符串列表。不读磁盘 | 参数不是字符串 |
| `text.join` | 字符串列表，分隔字符串 | 字符串 | 元素不是字符串 |
| `utf8.encode` | 字符串 | 字节 | 参数不是字符串 |
| `utf8.decode` | 字节 | 字符串 | 非法 UTF-8 |
| `base64.encode` | 字节 | 不换行的标准 base64 字符串 | 参数不是字节 |
| `base64.decode` | 字符串 | 字节 | 非法字符 |

## 列表

这些行为都返回新列表，不改传入的那一份。空列表上的 `where`、`pick`、`sort`、`group` 得到空列表。`join` 任一侧为空时得到空列表。

| 行为 | 参数 | 返回 | 失败 |
| --- | --- | --- | --- |
| `list.of` | 零个或多个值 | 列表 | |
| `list.len` | 列表 | 整数 | 参数不是列表 |
| `list.add` | 列表，值 | 末尾多一项的列表 | 第一个参数不是列表 |
| `list.set` | 列表，整数下标，值 | 该下标被替换的列表 | 下标越界 |
| `list.remove` | 列表，整数下标 | 删掉该项的列表 | 下标越界 |
| `list.map` | 列表，一个参数的行为 | 各项 `result` 组成的列表 | 行为没有 `set(result, ...)` |
| `list.keep` | 列表，一个参数的行为 | `result` 为真时留下的原项 | 行为没有 `set(result, ...)` |
| `list.update` | 同一结构的记录列表，字段名，值 | 该字段被替换的列表 | 结构混杂、字段不存在或类型不符 |
| `list.where` | 记录列表，字段名，值 | 该字段等于值的记录 | 字段不存在 |
| `list.pick` | 记录列表，结果结构名 | 按结果结构字段名复制的记录 | 来源没有该字段或类型不符 |
| `list.sort` | 记录列表，字段名。`order: "desc"` 为降序，省略为升序 | 排序后的列表。同值保持原顺序 | 字段不是 `str`、`int`、`float` 或 `bool` |
| `list.group` | 记录列表，字段名，结果结构名 | 分组记录。组的顺序是首次出现的顺序 | 结果结构不是该字段再加一个元素为来源结构的 `list` 字段 |
| `list.join` | 左列表，左字段，右列表，右字段，结果结构名 | 两边字段相等的记录 | 连接字段类型不同，或结果字段在两边冲突且值不同 |

## 对象

`object(键, 值, ...)` 的键是字符串，个数必须成对。返回没有结构的对象。

## 包

| 行为 | 参数 | 返回 | 失败 |
| --- | --- | --- | --- |
| `pack` | 包内名字，同一 `split` 或 `json` 结构的记录列表。`key: "密钥路径"` 可选 | 该列表。清单记下结构编号 | 没有 `lib`、空列表、结构混杂，或名字含 `/`、`\`、`..` |
| `unpack` | 路径。加密项必须带同一把 `key` | 记录列表 | 清单没有这项、`struct` 为空、短名不唯一，或文件不是 UTF-8 |

`pack` 的密钥文件不存在时写入新的 32 字节十六进制密钥。同一次运行里刚 `pack` 过的名字，`unpack` 直接用那份记录。

## 仓库

| 行为 | 参数 | 返回 | 失败 |
| --- | --- | --- | --- |
| `repo.put` | 已有的包目录 | 仓库里的正式目录字符串 | 没有 `repo`，清单对不上，版本已存在，或超过容量、包数 |
| `repo.get` | 名字，版本 | `dir/名字/版本` | 没有这份包 |
| `repo.fetch` | 基址，名字，版本，还不存在的目标目录 | 目标目录字符串 | 任一步失败时删掉目标目录 |
| `repo.push` | 基址，包目录 | 布尔值 true | 对方拒绝，或目录里有 `dake.key` 以外对不上的文件 |

`repo.fetch` 与 `repo.push` 自己写 HTTP，正文按 1 MiB 一块搬运。TLS 的信任锚用当前 `net.url` 的 `ca`。路径、状态码和提交规则见[语言](language.md)的「仓库」。

## 网络

| 行为 | 参数 | 返回 | 失败 |
| --- | --- | --- | --- |
| `net.url` | 基址 `http` 或 `https`。`name`、`headers`、`ca`、`cert`、`key`、`timeout` 可选 | 布尔值 true，并设为当前目标 | 方案不对，或 `cert` 与 `key` 不成对 |
| `net.get` | 结构名可省略。路径可写在结构名前，且以 `/` 开头。`url: "名字"` 选用具名目标 | 省略结构时是字节，否则是一条记录 | `4030` 地址，`4031` 连接，`4032` TLS，`4033` 状态码不在 200–299，`4034` 请求头或超时 |
| `net.post` | 正文是字节、字符串或记录。结构名可写在正文后。路径可写在正文前 | 与 `net.get` 相同 | 与 `net.get` 相同 |
| `net.accept` | `主机:端口`，结构名，行为。行为一个参数只收记录，两个参数时第二个是请求头对象。`cert` 与 `key` 成对可选 | 行为的 `result`，必须是记录或字节。只接一个请求 | 地址不是 `主机:端口`，`cert` 与 `key` 不成对，或行为没有 `set(result, ...)` |

`headers` 是记录。字段名的 `_` 变成 `-`，每段首字母大写。值必须是字符串。调用上的 `headers` 按连线后的名字覆盖。未给出 `Content-Type` 时：`json` 为 `application/json`，字节或 `width` 为 `application/octet-stream`，其余文本为 `text/plain; charset=utf-8`。`timeout` 是正整数秒，省略为 30。`ca` 是 PEM 信任锚。省略 `ca` 时用系统根证书。

## 数据

| 行为 | 参数 | 返回 | 失败 |
| --- | --- | --- | --- |
| `data.re` | 模式 | 该模式字符串 | 正则不能编译 |
| `data.re.find` | 模式，文本 | 第一处匹配的字符串 | 没有匹配 |
| `data.re.group` | 模式，文本，非负整数编号 | 该捕获组。编号 0 是整段匹配 | 没有匹配或没有该组 |
| `data.re.all` | 模式，文本 | 全部匹配的字符串列表 | 正则不能编译 |
| `data.re.replace` | 模式，文本，替换 | 替换全部匹配后的字符串 | 正则不能编译 |
| `data.vali` | 验证器名，然后是字段名和值，或只有一个字符串 | 布尔值 true | 未知验证器或检查失败 |
| `data.seria` | `json` 或 `bin`，值 | `json` 返回字符串，`bin` 返回字节 | 未知格式。字节不能直接序列化 |
| `data.deseria` | `json` 加字符串，或 `bin` 加字节 | 布尔值、整数、小数、字符串、列表或对象 | 格式不对 |
| `data.comp` | 字节或字符串。可选地先给整数级别：`1` 快，`19` 最好，其他整数为自定义级别 | 压缩后的字节 | 参数不是字节或字符串 |
| `data.decomp` | 字节 | 字节 | 不是压缩数据 |

`data.vali` 的验证器名是 `not_empty`、`email`、`url`、`numeric`、`alpha`、`alphanumeric`。

## 宿主

每次调用采样一次。返回没有结构的对象。这些值不写入清单。

| 行为 | 参数 | 字段 |
| --- | --- | --- |
| `sys.host` | 无 | `name`、`os`、`version`、`kernel`，皆为字符串 |
| `sys.cpu` | 无 | `usage` 小数百分比，`logical`、`physical` 整数 |
| `sys.mem` | 无 | `used`、`total`、`swap_used`、`swap_total`，字节整数 |
| `sys.disk` | 已存在的路径 | `name`、`mount`、`free`、`total`。`free` 与 `total` 是字节整数 |
| `sys.disks` | 无 | 上述磁盘对象的列表 |

`sys.disk` 的路径不存在时失败码是 `3002`。
